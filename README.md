# Elmbrook: Night Market

A cozy roguelike deckbuilder: run a potion stall in Elmbrook for one lunar month. Brew ingredients into potions for townsfolk, pay rent every week, and survive the Night Market on moon nights.

## Run it

```sh
pnpm install
pnpm dev
```

Open the printed URL. In VS Code: Command Palette → **Simple Browser: Show** → paste the URL, and the game sits in a panel next to Claude Code, reloading on every save.

Jump straight to a screen: `?fixture=hand`, `?fixture=art`, or start a seeded run with `?fixture=hand&seed=my-seed`.
